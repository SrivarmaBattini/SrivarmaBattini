## About Me

I'm a Machine Learning / AI Developer interested in building intelligent systems that are useful beyond a notebook or prototype. I enjoy working across the development process—from understanding a problem and experimenting with models to connecting those models to reliable applications.

My projects explore different sides of applied AI: understanding the nuances of written communication, making learning and scheduling decisions, connecting computer vision to physical devices, and building backend infrastructure for inference. I value thoughtful experimentation, clear engineering, and learning by building.

**My goal is simple: turn interesting ideas into practical, well-designed systems.**

## Featured Projects

<table>
<tr>
<td width="50%" valign="top">

### [EmailIQ ↗](https://github.com/SrivarmaBattini/EmailIQ)

An email intelligence tool that examines tone, intent, urgency, politeness, sarcasm, passive aggression, and shifts in tone across a thread. Custom DeBERTa models power the analysis, while retrieval-assisted LLM rewriting helps users refine messages with context in mind.

**Built with:** Python, DeBERTa, FAISS, Groq, FastAPI, Supabase

</td>
<td width="50%" valign="top">

### [ML Recall ↗](https://github.com/SrivarmaBattini/MLRecall)

An adaptive memory-review scheduler that models retention as a Restless Multi-Armed Bandit problem. Its QWI approach combines Q-learning, Whittle Index prioritization, and memory-decay modeling to study review policies under limited resources.

**Built with:** Python, Reinforcement Learning, RMAB, Optimization, FastAPI

</td>
</tr>
<tr>
<td width="50%" valign="top">

### [Auto Aim Laser Turret ↗](https://github.com/SrivarmaBattini/Auto-Aim-Laser-Turret)

A computer-vision and robotics project that tracks targets from a live camera feed, estimates movement angles, and translates them into servo commands through a ROS 2 and Raspberry Pi setup.

**Built with:** Python, OpenCV, ROS 2, Raspberry Pi, Servo Control

</td>
<td width="50%" valign="top">

### [InferenceHub ↗](https://github.com/SrivarmaBattini/InferenceHub)

A backend service for managing machine-learning inference workloads. It includes API routing, database migrations, structured logging, request tracing, caching, and streaming-oriented components for a more operational approach to model serving.

**Built with:** Python, FastAPI, Docker, Gunicorn, Alembic
